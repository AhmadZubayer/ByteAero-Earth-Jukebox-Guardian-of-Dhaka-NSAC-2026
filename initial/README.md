# Earth Jukebox: Guardian of Dhaka

The playable web game is in [`sites/earth-jukebox-dhaka/`](sites/earth-jukebox-dhaka/). Serve this `initial/` folder with a local web server and open `index.html` to enter the game, or use the [published Site](https://earth-jukebox-guardian-of-dhaka.oaken-map-6488.chatgpt.site/).

The game includes real, dated NASA images, original image-driven sonification, six Dhaka story rounds, a [visual player guide](sites/earth-jukebox-dhaka/dist/guide.html), and a printable Earth Listener Ticket. The [player journey](sites/earth-jukebox-dhaka/plan.md) explains each step in plain language.

The former video-production package has been removed. The Site folder is the single source for the playable game and its assets.
