# Earth Jukebox: Guardian of Dhaka

A visual sound story for younger players, created by Team BYTEAERO at AIUB, Dhaka for the NASA Space Apps Challenge 2026.

**[Play the game](https://earth-jukebox-guardian-of-dhaka.oaken-map-6488.chatgpt.site/)** · [Player guide](https://earth-jukebox-guardian-of-dhaka.oaken-map-6488.chatgpt.site/guide.html) · [Game source](initial/sites/earth-jukebox-dhaka/) · [Player journey](initial/sites/earth-jukebox-dhaka/plan.md)

The player meets Echo, scans real NASA Earth images to hear original image-driven sounds, follows six Dhaka story years, chooses an imagined future path, and receives a printable Earth Listener Ticket. The game also has written sound clues, a sound toggle, and a guide covering every step.

The 1884 and 2022 global frames and 2000–2024 Dhaka images are dated NASA views. The 2035 and 2050 scenes, characters, and choice outcomes are imagined. The audio is made by the game from image features; it is inspired by NASA sonification examples and is not official NASA audio or a temperature reading.

To run the game locally, serve the `initial/` folder with a local web server and open `initial/index.html`. It redirects to the playable web game. The active Site source and all game assets are in `initial/sites/earth-jukebox-dhaka/`.
